# Ganpati Digital Invitation

This is a mobile-first digital invitation inspired by the dark, cinematic + gold Ganpati invitation style in your reference video.

## Files
- index.html — invitation content
- style.css — design and animations
- script.js — scroll reveal, countdown and music
- music.mp3 — optional; add your own royalty-free audio

## Before publishing
Open index.html and replace:
- [दिनांक येथे]
- [वेळ येथे]
- [पत्ता येथे]
- [पूर्ण पत्ता येथे]
- [आपले नाव / परिवाराचे नाव]
- event schedule values

Then edit the `eventDate` in script.js.

## Publish for a shareable link
The easiest free option is GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html, style.css and script.js.
3. Open Settings → Pages.
4. Choose Deploy from branch → main → /root.
5. GitHub will give you a public invitation URL.

You can then send that URL on WhatsApp.
